# Tourism‑Consumption‑Moderated‑Mediation
R‑language scripts for moderated‑mediation analysis of Chinese domestic tourist dataset

## Project Overview
This repository contains all R‑studio code for the manuscript:
> Origin‑market economic gradient, tourism expenditure and tourist satisfaction: evidence from moderated‑mediation model

The dataset with 136327 anonymous tourist travel records is hosted on Figshare for permanent storage.

## Code Content
1. Data cleaning and outlier screening
2. Descriptive statistics & correlation test
3. Mediation effect test (tourism expenditure as mediator)
4. Travel‑mode moderated effect analysis
5. U‑shaped nonlinear regression between expense and satisfaction
